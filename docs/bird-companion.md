# 小黄鸟桌面形象

在 **设置 → 外观 → 小黄鸟虚拟形象** 中调整两个独立开关：

- **常驻显示小黄鸟**：默认关闭。开启后小黄鸟留在桌面，普通任务也会显示“词元鸟正在思考 / 搜索 / 编辑”等进度。
- **使用电脑时自动显示**：默认开启。会话尝试调用 `computer_use` 或内置 `desktop-control` 命令时出现；等待授权时也会出现。关闭此选项后不会因电脑操作而自动弹出。

小黄鸟使用原软件图标做分层 2D 动画，保留黑色外套、蓝色面板和挥翅姿势，头部、眼睛、嘴部、翅膀独立表现。当前使用 SVG 参数化动画，尚未接入 Live2D Cubism SDK 或 `.moc3` 模型。默认仅在尝试电脑操作时唤醒，初始位置为主屏幕工作区右下角；普通聊天和普通工具调用不会唤醒。软件最小化后仍可显示，出现时不会抢走当前窗口焦点。系统开启减少动态效果时停止动画，保留当前状态的静态表情。

右键点击小黄鸟打开菜单：可以查看进度、手动挥翅打招呼、点头或伸懒腰；**本次运行中隐藏**会同时收起鸟和气泡，后续任务不会再次唤醒，重启软件或修改小黄鸟设置后恢复。**关闭小黄鸟**会保存关闭两个显示开关，重启后也保持关闭；在 **设置 → 外观** 中重新开启。两种操作都不会中断任务。

动作和表情根据任务状态即时生成，无需额外模型调用：思考时歪头，搜索/查看屏幕时左右观察，阅读时低头，编辑/输入时轻拍翅膀，点击时点按，移动/拖拽/滚动时指向，等待授权时好奇注视，完成时微笑跳跃，步骤出错或拒绝授权时皱眉摇头，中断时休息。拖动鸟本体时显示提起动作。多任务并发时优先显示等待确认的任务；手动动作不会覆盖错误表情，并在短暂播放后恢复当前任务动作。表情仅使用进度元数据，不读取聊天正文来推断情绪。

鸟本体和进度气泡使用两个独立的透明窗口。关闭气泡只收起气泡，小黄鸟继续显示和执行动画；点击小黄鸟可以重新打开当前进度，待命时点击可打招呼。拖动小黄鸟可调整位置，打开的气泡会跟随移动，并根据文字自动调整高度。气泡关闭后不会因同一任务的普通进度更新反复弹出，任务结束时仍会给出结果提示。关闭气泡不会中断任务。

气泡显示当前操作和已完成的工具步骤数；同时执行多个任务时会标注任务数量。它不猜测百分比，也不展示输入文字、密码、原始工具返回值或聊天正文。结束、异常和中断分别提示；结束通知保留 10 秒，自动显示模式随后收起，常驻模式回到待命状态。执行结束不等同于目标已验证成功，请在聊天中查看最终结果。

设置保存在本机 `preferences.json` 的 `birdCompanion` 字段，连接远程服务器时也使用本机设置。桌面形象目前由 Electron 客户端提供，网页版和 Android 不显示此设置。自动进度跟随标准会话工具事件；通过其他任意脚本间接调用系统自动化的行为没有统一识别保证。

Windows 上使用系统的捕获排除机制，防止小黄鸟遮挡 computer use 的截图；其他系统的捕获排除效果取决于操作系统支持。

拖动和屏幕工作区变化时，鸟本体的内容区固定为 236 × 200，气泡宽度固定为 320，仅文字变化会调整气泡高度。窗口创建时也会校正内容尺寸，避免 Windows 分数缩放下首次移动变小或连续移动逐步变大。

## 开发验证

```powershell
bun test apps/electron/src/main/__tests__/bird-companion-progress.test.ts
bun run typecheck:electron
bun run electron:build:main
bun run electron:build:preload
bun run electron:build:renderer
bun run scripts/tokenbird-bird-companion.smoke.ts
```

原生冒烟检查会验证 150 次连续移动及 20 次屏幕工作区更新后的内容尺寸、渲染视口和截图像素尺寸，并覆盖气泡关闭后的移动。
